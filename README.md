### About

IT student at MIT Manipal who likes building backend systems properly: typed APIs, real databases with
migrations, tests, and a one-command Docker setup. Recently that has meant an LLM gateway, a security layer
for AI agents, and a couple of full-stack apps, alongside ML work and daily DSA practice in C++.
